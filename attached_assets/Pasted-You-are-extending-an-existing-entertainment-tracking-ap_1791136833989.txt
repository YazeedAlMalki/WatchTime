You are extending an existing entertainment-tracking app called WatchTime.

Build a complete, polished feature called Discover by Mood. It helps a user choose a movie based on how they want to feel, what they want to avoid, how much time they have, and what they can actually watch.

This must be a native WatchTime feature—not a separate product, separate brand, standalone landing page, or generic streaming-service clone.

Product Context

WatchTime is a film and TV tracking app. Users can track what they have watched, rate titles, add titles to a watchlist, track rewatches and progress, and discover what to watch next.

The problem this feature solves is:

A user often has access to many movies but cannot decide what fits their mood right now.

Genre is not enough. A user may want a comedy that is not childish, a drama that is not depressing, a family film with no disturbing content, or a serious film that is still hopeful.

Discover by Mood should answer:

“What should I watch tonight, given my mood, limits, time, and WatchTime history?”

Core Product Principles

1. Mood before genre
    Start with the experience the user wants, not “action,” “comedy,” or “drama.”
2. Practical limits matter
    A perfect match is useless if it is too long, unavailable, unsuitable for the people watching, or contains content the user wants to avoid.
3. Explain every recommendation
    Never show an unexplained black-box recommendation. The user must understand why a movie was suggested.
4. Do not treat match score as quality
    A 94% match means “strong fit for your current request,” not “this is objectively a 94/100 film.”
5. Respect the user’s history
    By default, avoid recommending films that the user has already marked as watched, dismissed, or rated poorly. Allow the user to include rewatches when they want comfort viewing.
6. Sensitive content needs clear information
    Be transparent about violence, sexual content, gore, disturbing themes, and animal harm. Do not use vague labels alone.
7. User control comes first
    The user should be able to refine results, remove a filter, dismiss a film, save it, or choose “surprise me” at any point.

Exact matching sequence

Follow this order:

Step 1: Apply hard filters

Remove titles that violate non-negotiable criteria:

* Exceed the maximum runtime
* Are unavailable in the selected region or selected services
* Do not meet language or subtitle requirements
* Exceed selected content boundaries
* Are unsuitable for the selected age requirement
* Are already watched, dismissed, or excluded by WatchTime history settings

A movie that fails a hard filter must never appear just because it has a high mood score.

Step 2: Score mood compatibility

For each remaining movie:

1. Compare the movie’s mood values against the user’s selected mood values.
2. Calculate how close each value is.
3. Use the user’s importance level as a weight:
    * Nice to have = low weight
    * Important = medium weight
    * Must match = high weight
4. Penalise titles that are far from a “Must match” mood preference.
5. Add a small boost for:
    * A film saved to a relevant list
    * A film similar in mood to titles the user rated highly
    * A film the user has not seen before
6. Apply a small diversity adjustment so the first results are not all from the same genre, country, director, or decade.

Convert the result into a matchScore from 0 to 100.

The match score must mean:

How compatible this movie is with this user’s current request.

It must not mean:

* Critical quality
* Popularity
* IMDb rating
* Cultural importance
* Universal recommendation

Step 3: Generate transparent reasons

For every recommendation, generate three to five factual reasons based on the user’s actual choices.

Example:

Why it matches

* Strongly hopeful tone
* Low violence and no gore
* Runtime: 104 minutes
* Available with Arabic subtitles
* Similar in mood to films you rated highly

If a recommendation is a near match rather than an exact match, state the trade-off.

Example:

One trade-off
It is more emotionally intense than you selected.

Language, Region, and Accessibility

The feature must fully support English and Arabic.

* Add an EN / العربية toggle.
* Switch all layout, icon direction, and text alignment to RTL when Arabic is selected.
* Translate all labels, explanations, filters, empty states, and feedback controls.
* Use high-quality Arabic typography.
* Ensure Arabic text is never truncated or broken on mobile.
* Use accessible colour contrast.
* Support keyboard navigation and visible focus states.
* Do not communicate content warnings or match quality through colour alone.
* Add meaningful alt text to posters and backdrop images.

Visual Design Requirements

The feature must look native to WatchTime while feeling cinematic and premium.

* Use WatchTime’s existing design system, spacing, typography, and navigation patterns.
* Use a dark charcoal base with warm light text.
* Use restrained accent colours rather than bright, noisy gradients.
* Use posters and backdrops as emotional cues, but preserve text readability.
* Add subtle transitions when switching presets, updating sliders, or revealing results.
* Optimise for mobile first.
* Avoid overusing carousels.
* Avoid a dense, database-like appearance.
* Make the experience feel calm and decisive, not overwhelming.

Technical Requirements

* Use Next.js, TypeScript, and Tailwind CSS.
* Build reusable components.
* Keep data, recommendation logic, UI state, and presentation components separate.
* Use deterministic client-side recommendation logic for the prototype.
* Store saved titles, dismissed titles, filters, language, and the current discovery session in localStorage.
* Use realistic seeded movie data.
* Do not require a backend, API key, authentication flow, payment flow, or chatbot for the initial prototype.
* Do not include non-functional buttons or fake controls.
* Keep the code structured so real licensed movie, content-guide, and streaming-availability data can later replace mock data.

Scope Boundaries

Do not build these in the first version:

* A conversational AI recommendation assistant
* Social feeds or follower systems
* Payments or subscriptions
* Full streaming playback
* Real-time streaming availability unless a licensed source is already connected
* Automatic claims about religious, moral, or psychological suitability

Acceptance Criteria

The completed feature is successful only if a user can:

1. Enter Discover by Mood from WatchTime.
2. Select a quick preset or customise mood sliders.
3. Set runtime, language, availability, content, and history filters.
4. Receive only movies that satisfy hard filters.
5. See ranked matches with truthful explanations.
6. Understand why a movie is recommended and any important trade-off.
7. Open a detailed spoiler-free movie page.
8. Save, dismiss, mark watched, and rate a title.
9. Use the entire experience in English and Arabic with correct RTL layout.
10. Receive a useful no-results experience rather than a blank page.
