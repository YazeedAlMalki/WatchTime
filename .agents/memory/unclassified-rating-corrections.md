---
name: Unclassified rating corrections
description: Safety boundary for manually correcting unsupported provider rating classifications.
---

When an admin corrects an unsupported rating classification, change only the selected item's regional classification system. Preserve its provider-supplied label, score, maximum score, and description. If no classification item exists to correct, dismissal is safer than creating replacement rating data.

**Why:** A system correction can place an existing provider label in a regional rating list, but changing the label or score would create provider-attributed data that was not supplied by the provider.

**How to apply:** Keep future review actions narrowly scoped to verifying the category and routing the original provider value to its matching region. Use dismissal when the source record cannot be mapped safely.
